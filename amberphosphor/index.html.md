# Amber Phosphor

Canonical: https://freew.org/amberphosphor/

A terminal theme for Apple Terminal and iTerm2.

Amber phosphor terminal theme for Apple Terminal and iTerm2. PC-12 phosphor #FFB000 on #1A1000.

It uses the PC-12 phosphor color, #FFB000, on background #1A1000. Bold text is #FFD066. The cursor is #FFB000.

Foreground #FFB000 on #1A1000.

## Profiles

- Amber Phosphor: Every ANSI color is a brightness of amber, from #332200 to #FFE099.
- Amber Phosphor ANSI: The same base, with warm colors so ls and git diff stay readable. Red #FF6622, green #88AA00, yellow #FFB000, blue #CC8844, magenta #DD7744, cyan #AAAA33.

## Use

- Font: Menlo Regular, 14 points.
- System: macOS, in Terminal.app or iTerm2.
- Source: https://github.com/JohnThre/AmberPhosphor-theme
- Terminal.app installs with `./terminal/install-terminal.sh`. iTerm2 installs with `./iterm2/install-iterm2.sh`.

Programming language: Swift.
