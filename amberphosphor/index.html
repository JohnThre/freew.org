Amber Phosphor

Terminal theme Free software · GPL-3.0

A terminal theme for Apple Terminal and iTerm2.

Source License

It uses the PC-12 phosphor color, #FFB000, on background #1A1000. Bold text is #FFD066. The cursor is #FFB000.

Profiles

Amber Phosphor
Every ANSI color is a brightness of amber, from #332200 to #FFE099.
Amber Phosphor ANSI
The same base, with warm colors so ls and git diff stay readable. Red #FF6622, green #88AA00, yellow #FFB000, blue #CC8844, magenta #DD7744, cyan #AAAA33.
