# freew.org

Static presentation for apps and repositories you can use without paying, including free software. The catalog lists [Amber Phosphor](https://freew.org/amberphosphor/), a terminal theme for Apple Terminal and iTerm2. It is free of charge, and it is free software under the GNU General Public License, version 3. The source is https://github.com/JohnThre/AmberPhosphor-theme. The catalog also lists [RockyBack](https://freew.org/rockyback/), which prepares Rocky Linux 9 or AlmaLinux 9 and installs ClambBack. RockyBack is free of charge. It is proprietary, and it is not free software. The source is https://github.com/JohnThre/rockyback.

Author: Pengfan Chang (Swipht Group).

- Main site: https://swiphtgroup.com/
- Related site: https://clambercloud.com/

The previous game is archived in the private repository `freedom-wuxia`. This site is HTML, CSS, and XML. Serve the directory with a static file server and open `/`.
