# freew.org

**Know what is free. Know what is not.**

Static HTML and CSS site (zero JavaScript, zero TypeScript, zero `<script>` tags) that lists apps and repositories and states the terms of each. Six works are free software under the GNU GPL. Five works are proprietary, and their published licenses grant no permission to use them.

The catalog lists [Air Traffic Control (ATC)](https://freew.org/atc/), which runs and coordinates coding agents from the Nova editor. Its published license grants no permission to use it. It is proprietary, and it is not free software. The source is https://github.com/JohnThre/AirTrafficControl.novaextension. The catalog lists [Amber Phosphor](https://freew.org/amberphosphor/), a terminal theme for Apple Terminal and iTerm2. It is free of charge, and it is free software under the GNU General Public License, version 3. The source is https://github.com/JohnThre/AmberPhosphor-theme. The catalog lists [COBOL](https://freew.org/cobol/), COBOL support for the Nova editor. Its published license grants no permission to use it. It is proprietary, and it is not free software. The source is https://github.com/JohnThre/COBOL.novaextension. The catalog lists [CTMU](https://freew.org/ctmu/), a command-line tool for macOS. It is free of charge, and it is free software under the GNU General Public License, version 3. The source is https://github.com/JohnThre/CTMU-for-macOS. The catalog lists [Gas Plasma](https://freew.org/gasplasma/), an orange-dominant dark theme for Apple Terminal, iTerm2, VS Code, and Zed. It is free of charge, and it is free software under the GNU General Public License, version 3 or later. The source is https://github.com/JohnThre/GasPlasma-theme. The catalog lists [iB-theme](https://freew.org/ibtheme/), an IBM Carbon theme for Cursor, VS Code, GNU Emacs, Vim, Neovim, CotEditor, Apple Terminal, and iTerm2. It is free of charge, and it is free software under the GNU General Public License, version 3 or later. The source is https://github.com/JohnThre/iB-theme. The catalog lists [NovaCEE Offline](https://freew.org/novacee/), offline docs and developer tools in the Nova editor, for Macs without a network connection. Its published license grants no permission to use it. It is proprietary, and it is not free software. The catalog lists [P1PW](https://freew.org/p1pw/), a warm, paper-toned light theme for Apple Terminal. It is free of charge, and it is free software under the GNU General Public License, version 3. The source is https://github.com/JohnThre/P1PW-theme. The catalog lists [Pascal](https://freew.org/pascal/), Pascal and Object Pascal support for the Nova editor. Its published license grants no permission to use it. It is proprietary, and it is not free software. The source is https://github.com/JohnThre/Pascal.novaextension. The catalog lists [VB.NET](https://freew.org/vbnet/), Visual Basic .NET support for the Nova editor. Its published license grants no permission to use it. It is proprietary, and it is not free software. The source is https://github.com/JohnThre/VB.NET.novaextension. The catalog also lists [WordPerfect Blue](https://freew.org/wordperfectblue/), a WordPerfect 5.1 white-on-blue theme for Apple Terminal. It is free of charge, and it is free software under the GNU General Public License, version 3. The source is https://github.com/JohnThre/WordPerfectBlue-theme.
