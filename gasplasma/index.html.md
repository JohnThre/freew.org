# Gas Plasma

Canonical: https://freew.org/gasplasma/

An orange-dominant dark theme for Apple Terminal, iTerm2, VS Code, and Zed.

Orange-dominant dark theme. Foreground #FF8C00 on background #1A0A00.

Foreground is #FF8C00 on background #1A0A00. Bold text is #FFD2A6. The cursor is #FF8C00.

Foreground #FF8C00 on #1A0A00.

## Surfaces

- Apple Terminal: Import GasPlasma.terminal. macOS 26.4 or later.
- iTerm2: Import GasPlasma.itermcolors, then select the GasPlasma preset.
- VS Code and Open VSX: Extension jpfchang.gas-plasma-theme, with Gas Plasma Icons and Gas Plasma Product Icons.
- Zed: Gas Plasma Theme and Gas Plasma Icons.
