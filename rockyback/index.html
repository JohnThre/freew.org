RockyBack

Server setup script Proprietary · no permission to use

Prepares Rocky Linux 9 or AlmaLinux 9 and installs ClambBack.

Source License

It updates the host, hardens common attack surfaces, checks DNS and TLS, then installs a signed ClambBack RPM. On AWS, it reminds you to open matching ports in the AWS firewall.

Host

System
Rocky Linux 9 or AlmaLinux 9 on x86_64.
Access
Root or sudo, with SELinux enabled.
Name
A real hostname whose DNS matches the public address.

Terms

No public permission
The published license does not allow use, copying, or sharing. Written authorization from the author is required.
Not free software
Proprietary. The license grants no other rights.

Use

These steps apply only with the author's written authorization.

SSH key
Install an SSH public key and confirm key login before running the installer.
Installer
Run ./install.sh. Interactive, --dry-run, or --yes.
