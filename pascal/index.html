Pascal

Nova extension Proprietary · no permission to use

Pascal and Object Pascal support for the Nova editor.

Source License

Not free software. The published license grants no permission to use, copy, or share Pascal. Written authorization from the author is required.

It highlights Free Pascal and Delphi source, lists units, types, and routines in the symbol list, and completes keywords, runtime names, and the names declared in the open file. Saving a file runs the Free Pascal compiler and marks errors in the editor. A Free Pascal task builds, runs, and cleans the program, and Format uses ptop.

Transcript

Pascal for Nova, from Swipht Group. Open a Pascal or Object Pascal file, and Nova highlights it, with a symbol list for your classes and routines. Save, and Free Pascal checks your code, so errors appear right in the editor. Build, run, and clean from the Free Pascal task. Format with ptop, and start new programs and units from clips. It needs Nova 11 or later. Find Pascal in the Nova Extension Library.

Surfaces

Nova
Nova 11 or later on macOS. Install it from the Extension Library.
Free Pascal
Optional. Build, run, clean, and save-time diagnostics use fpc on your PATH, or a compiler path set in preferences.
Language server
Optional. Set an executable path in preferences. The extension does not download or bundle a server.
