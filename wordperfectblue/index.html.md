# WordPerfect Blue

Canonical: https://freew.org/wordperfectblue/

A WordPerfect 5.1 white-on-blue theme for Apple Terminal.

WordPerfect 5.1 white-on-blue theme for Apple Terminal. Foreground #FFFFFF on background #00007B.

Foreground is #FFFFFF on background #00007B. Bold text is #E0E8FF. The cursor is #FFFFFF.

Foreground #FFFFFF on #00007B.

## Surfaces

- Apple Terminal: Import WordPerfectBlue.terminal. macOS 26.4 or later.
